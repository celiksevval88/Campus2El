
# Campus2El — Kampüs İçi İkinci El Alım-Satım Platformu

## Proje Hakkında

Campus2El, üniversite öğrencilerinin kampüs içerisinde ikinci el ürünlerini alıp satabilmelerini amaçlayan bir web projesidir. Kullanıcıların ürünleri görüntüleyebileceği, ilanları inceleyebileceği ve ürünlerini satışa sunabileceği bir platform olarak tasarlanmıştır.

## Özellikler

- Ürünleri ve ilanları görüntüleme
- İlan detaylarını inceleme
- Yeni ilan ekleme
- Kullanıcı kayıt ve giriş sayfaları
- Kullanıcı profil sayfası
- Yönetici paneli
- İlan ve kullanıcı yönetimi
- İletişim sayfası

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript

## Çalıştırma

Projeyi bilgisayarınıza indirdikten sonra `index.html` dosyasını bir web tarayıcısında açabilirsiniz.

## Amaç

Kampüs içerisindeki ikinci el alışverişi kolaylaştırmak ve HTML, CSS ve JavaScript kullanarak işlevsel bir web arayüzü geliştirmek.
